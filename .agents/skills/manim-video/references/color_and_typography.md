# 3Blue1Brown 质感审美指南：色彩与数学排版规范

数学可视化不仅要“正确”，更要具备**直觉穿透力**与**令人舒适的高级美感**。本规范提供专业级数学动画的色彩心理学与排版体系。

---

## 一、深色背景哲学 (Background Palette)

严禁直接使用纯黑色 (`#000000`) 或刺眼的高对比纯白色背景。
纯黑容易导致视神经疲劳，缺乏深度空间感。

- **标准深色空间基底**：`#121417` 或 `#18181B`（柔和炭黑带微蓝灰）
- **舞台卡片底板**：`#1F242D`（用于划分左右对比分区）
- **文字主色**：`#F3F4F6`（柔和象牙白，避免 `#FFFFFF` 的过曝感）
- **辅助说明/弱化信息**：`#9CA3AF`（灰阶）

---

## 二、功能性语义色彩系统 (Semantic Color Palette)

在数学视频中，颜色是有“含义”的，同一种数学概念在全片中必须保持色彩一致！

| 色彩角色 | Hex 颜色值 | 典型用途与几何语义 |
| :--- | :--- | :--- |
| **Primary (天蓝)** | `#3B82F6` | 主体函数曲线、主多边形、输入变量 $x$、向量 $\vec{v}$ |
| **Secondary (活力橙)**| `#F97316` | 变化量 $\Delta x$、辅助线、对照组、输出变量 $y$ |
| **Accent (启迪黄)** | `#EAB308` | 核心结论、高光边框、极值点、顿悟 Aha! 瞬间 |
| **Positive (薄荷绿)**| `#10B981` | 积分面积、正确推导路径、正向增长趋势 |
| **Alert (珊瑚红)** | `#EF4444` | 反例、奇点、不连续点、约束边界 |
| **Auxiliary (梦幻紫)**| `#8B5CF6` | 复数虚部、高维映射、基底变换矩阵 |

> **关键准则**：单个画面内的主色调不要超过 3 种，避免变成彩虹涂鸦。

## 三、屏幕空间构图法则 (Screen Layout Rules)

标准 16:9 构图下，建议采用以下三种经典构图：

### 1. 左右分屏对照构图 (Left: Geometric, Right: Algebraic)
- **左半屏 ($X \in [-6.0, -0.5]$)**：几何直观动画（坐标轴、动态图象、旋转形变）
- **右半屏 ($X \in [0.5, 6.0]$)**：代数推导、矩阵表达式、符号演进
- **视觉联结**：几何中的某部分（如切线斜率用橙色）与代数中的导数符号用完全相同的橙色相互呼应。

### 2. 居中演进构图 (Focused Transformation)
- 适合大型无字证明（如拼图法证明高维定理）。
- 主体居中，上下留出字幕与标题安全带。

### 3. 三段式时间推进构图
- 顶部标题行始终固定，中间核心区域动态演算，底部常驻单行解说旁白。

## 四、排版与字体阶梯 (Typography Scale)

| 层级 | 建议字号 (`font_size`) | 推荐组件与属性 |
| :--- | :--- | :--- |
| **一级大标题** | $40 \sim 48$ | `Text(..., font="Microsoft YaHei", weight=BOLD)` |
| **章节/二级标题** | $32 \sim 36$ | `Text(...)` |
| **主数学公式** | $36 \sim 44$ | `MathTex(r"...")` |
| **图表标注/轴标签** | $24 \sim 28$ | `MathTex` 或 `Text` |
| **底部旁白字幕** | $22 \sim 26$ | `Text(..., color="#9CA3AF")` |
